1. 为什么刚导入就显示节点全红/超时 (Timeout)？
#

  • 原因一（占比 75%）：电脑系统时钟与标准北京时间误差超过 60 秒。
    现代加密代理协议（如 VMess/Vless/Trojan）内置了严格的防重放攻击校验机制。如果你的电脑或手机时钟慢了或者快了哪怕一两分钟，服务端就会判定握手数据包非法并直接丢弃，导致测速全红。
    解决办法：进入 Windows“设置 → 时间和语言 → 日期和时间”，务必点击“立即同步”按钮；手机端打开“自动设置时间”开关。
  • 原因二：打开了客户端，但未开启“系统代理 (System Proxy)”。
    新手常以为只要把软件双击打开就自动代理了。实际上必须在 Clash Verge 或小火箭界面中，将“系统代理 (System Proxy)”开关拨到开启状态，浏览器请求才会走代理通道。
  • 原因三：本地宽带运营商 DNS 污染或缓存老化。
    如果在订阅配置刚更新后节点显示全红，建议在客户端中右键点击订阅执行“更新订阅 (Update)”；若依然不通，将系统或路由器的 DNS 更改为阿里公共 DNS（223.5.5.5）或腾讯公共 DNS（119.29.29.29）。

2. 遇到 YouTube 秒开但国内网页转圈：如何切换分流模式？
#

很多新手会纳闷：“为什么我挂上代理后，Google、YouTube 飞快，但是打开微信发图变慢了，甚至网易云音乐、淘宝打不开了？”

  • 病根所在：误选了“全局模式 (Global)”。
    在全局模式下，你设备产生的所有网络请求（包括微信聊天、百度搜索、看国内爱奇艺）都会强行绕道香港、美国或日本节点再折返回来。这不仅让国内服务延迟飙升卡顿，还会疯狂浪费你的机场订阅流量！
  • 正确姿势：务必将运行模式切换为“规则模式 (Rule)”。
    在规则模式下，客户端会通过内置的 GeoIP 和路由规则实现“智能分流”：访问百度、微信、知乎走本地宽带直连秒开；访问 Google、ChatGPT、YouTube 走专线代理。既省流量，又互不干扰。

3. 新手首月避坑三铁律：为什么建议优先月付体验？
#

  1. 网络“路由匹配度”存在千人千面差异：
    中国各大运营商（北方联通、南方电信、各地移动及广电）与机场入口机房的物理网络路由可能大相径庭。别人的体验只能作参考，唯有你自己用本地宽带连续测上一周（特别是 20:00 - 22:00 晚高峰），才能百分之百确定哪家机场与你的网络环境最契合。
  2. 对冲潜在跑路与维护风险：
    任何声称“买三年省 70%”但没有品牌信誉积累的小作坊机场，跑路风险都极高。先花 ¥18~23 体验一个月，即使中途发现自己不需要或不合适，试错成本也就是一杯饮料钱。
  3. 真实倍率自查法：
    买好套餐后，第一天可以在后台记录剩余流量，随后在 YouTube 上看完一部 4K 影片（约 3GB 流量），再刷新后台比对扣除的流量是否基本在 3GB 左右。如果看 3GB 被扣了 15GB，说明该机场存在恶意虚标暗坑倍率，应立即换乘。
