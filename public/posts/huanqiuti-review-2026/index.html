🛠️ 怎么在 Clash 中正确启用“防断流自动优选”？
#

1. 定位自动策略组
在客户端“代理（Proxies）”面板顶部，找到名为 “⚡ 自动选择 / AUTO” 或 “香港自动优选” 的策略组。

2. 保持自动选择状态
直接点选该自动优选组，避免手动锁定到某一个具体的单节点编号（如“香港01”）。

3. 享受无感防断流
当主节点因国际网络波动出现丢包时，客户端内核会在后台通过定时心跳探测，秒级无感切换至健康备用线路，彻底告别频繁手动切节点的麻烦。

五、新手常见误区提示：排坑避障 4 项原则
#

如果你按照指南导入后依然无法访问外网，请对照以下四点基础误区进行排查，95% 的问题都能迎刃而解：

1. 误区一：打开了软件，但忘记打开“系统代理”
#

许多刚用电脑端的小白，把 Clash Verge 下载并启动后就直接打开浏览器，发现依然无法上 Google。请记住：启动软件 ≠ 开启代理。必须在界面左侧或右下角托盘中，确认勾选了 “系统代理 (System Proxy)” 开关。

2. 误区二：浏览器插件存在端口冲突
#

如果你之前在 Chrome 或 Edge 上安装过诸如“SwitchyOmega”、“集装箱”或其他 VPN 插件，它们会强行接管浏览器的网络请求，导致客户端的系统代理失效。解决办法：在插件扩展管理中，将 SwitchyOmega 切换为“系统代理”或者直接暂时关闭该插件。

3. 误区三：电脑系统时钟误差超标
#

很多老电脑或重装过系统的机器，时钟往往比标准时间慢了几分钟。而现代代理协议（如 VMess/Vless/Trojan）如果客户端时间与服务端相差超过 60 秒，握手数据包会被判定为重放攻击而直接拒绝。请在 Windows 设置中点击“立即同步时间”。

4. 误区四：频繁全选节点一起测速
#

在节点列表中，偶尔点一次“测速延迟”是可以的，但请不要每隔几秒钟就疯狂点击右上角的批量测速按钮。短时间内向所有节点发送高频并发请求，不仅浪费带宽，还可能被服务端的抗 CC 防火墙识别为异常爬虫并临时阻断你的 IP。
