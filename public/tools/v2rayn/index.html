v2rayN 使用教程

v2rayN 是支持 Windows、Linux 和 macOS 的桌面图形客户端，可配合 Xray、sing-box 等核心使用。软件本身不包含可用线路。

官方下载与安装
#

从 v2rayN 官方 Releases 下载适合当前系统和架构的版本。只使用 2dust/v2rayN 官方仓库发布的文件，不建议从不明网盘或重新打包的网站下载。

Windows 用户解压或安装后运行 v2rayN；如果系统安全提示拦截，应先核对下载来源和文件名。Linux、macOS 用户应选择对应系统的发布包，并按发布说明安装。

添加订阅
#

  1. 打开客户端，进入“订阅分组”或版本中对应的订阅管理入口。
  2. 新建一个分组，填写别名并粘贴服务提供方给出的订阅地址。
  3. 保存后执行“更新全部订阅”。首次更新失败时，可尝试“不通过代理更新”。
  4. 更新成功后，服务器列表会显示可用节点。

选择节点与系统代理
#

  1. 在服务器列表中选择节点，可先执行延迟测试。
  2. 将选中的节点设为活动服务器。
  3. 在系统托盘菜单或主界面开启系统代理。
  4. 路由模式建议先使用客户端提供的默认规则；确有需要时再切换全局模式。

常见问题
#

  • 没有节点：确认订阅分组已保存，并手动更新订阅。
  • 核心启动失败：检查安全软件是否隔离了核心文件，或重新下载完整官方发布包。
  • 浏览器不能访问：确认系统代理已开启，活动服务器状态正常。
  • 部分应用无效：部分程序不遵循系统代理，需根据应用特性决定是否使用 TUN 模式。
  • 更新后配置异常：备份订阅分组，升级到官方稳定版后重新更新。

不同版本的菜单名称可能略有差异，可结合 v2rayN 官方 Wiki 查看当前界面说明。
